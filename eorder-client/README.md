# E-Order Management System Client

A modern React frontend for the E-Order Management System, built with Vite, Tailwind CSS v4, and Lucide icons.

## Features
- **Dashboard**: View and filter saved orders/drafts.
- **Create Order**: Initialize orders with distributor and period selection.
- **Order Details**: Select SKUs and quantities before final submission.
- **API Integration**: Connected to `eorder-api` on port 3002.

## Technology Stack
- **Framework**: React 19 (TypeScript)
- **Styling**: Tailwind CSS v4
- **State Management**: TanStack Query v5
- **Icons**: Lucide React
- **API**: Axios

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Ensure the backend is running**:
   Make sure `eorder-api` is running on `http://localhost:3002`.
